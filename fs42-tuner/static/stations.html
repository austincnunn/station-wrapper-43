Keep schedules going

FieldStation42 doesn't extend a station's schedule by itself, so without this a station goes off air when its scheduled days run out. When this is on, every station that already has a schedule is topped up to the number of days below. It only adds days; it never rebuilds anything, and it leaves a station alone while you are building it.

Captions

The language of the captions your videos are asked for: a .srt, .vtt or .ass file beside a video with the language in its name (Show - 01.en.srt), or a text track inside it. Stations carry them as a track a player can switch on; a block of a station's calendar can draw them on the picture instead.
